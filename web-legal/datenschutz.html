Datenschutzerklärung

Diese Website stellt das Browser-Spiel Sonnenhain RPG bereit. Das Spiel verwendet keine Werbe- oder Analyse-Cookies und bindet derzeit keine externen Analyse-, Werbe- oder Social-Media-Dienste ein.

Lokale Spielstände

Spielstände und Einstellungen werden lokal im Browser bzw. im von Godot bereitgestellten lokalen Speicher des jeweiligen Geräts gespeichert. Diese Daten werden durch das Spiel nicht an einen Spielserver übertragen.

Hosting

Die Website wird als statische Website über GitHub Pages ausgeliefert. Beim Abruf können technisch erforderliche Verbindungsdaten wie IP-Adresse, Zeitpunkt, angeforderte Datei und Browserinformationen durch den Hosting-Anbieter verarbeitet und protokolliert werden.

Mensch-Prüfung

Die derzeitige Mensch-Prüfung wird vollständig lokal im Browser ausgeführt. Dabei werden durch die Prüfung selbst keine Daten an einen CAPTCHA-Drittanbieter übertragen.

Cookies und Tracking

Das Spiel setzt keine Tracking- oder Marketing-Cookies. Es findet keine personalisierte Werbung statt.

Verantwortlicher

Die Angaben zum Betreiber und eine Kontaktmöglichkeit müssen vollständig im Impressum hinterlegt werden.
