# Local update scope

Combat synchronization, impact presentation, tower guards, menus, creation review, three-offer skill selection, optional class headgear and arena weapon catalogue.

Arena new weapon chance: waves 5–9 20%, 10–19 35%, 20–29 50%, 30+ 65%. Within each class all five names are equally likely. Headgear independent loot category in same roll: 2–8%, world chests 4%, dungeon reward 10%. Inventory-full arena rolls persist across retries and save/load.

New named weapons currently use existing weapon combat behavior and attributes. Proposed fifteen special weapon passives, new armor lines, five rings, leg/shoe slots and shared stat expansion remain concept-only and are not claimed as implemented.

Validation: regression scripts, two-client world/PvP vital/teleport/encounter tests, real WebSocket save/reconnect restoration including rings and headgear. Some test fixtures retain known exit cleanup warnings; no script errors accepted.
